# Medstudy-

**Medstudy-** — это веб-платформа (или интерактивное приложение), разрабатываемая для помощи студентам-медикам, ординаторам и практикующим врачам в изучении медицинских дисциплин, подготовке к экзаменам и систематизации знаний.

## 🎯 Цель проекта
Создать удобный, структурированный и доступный инструмент для эффективного освоения медицинского материала, прохождения тестов и разбора клинических случаев.

## 🚀 Текущий статус и технологии
Проект находится на самой ранней стадии разработки. 
* **Фронтенд:** HTML5 (в планах добавление CSS3 для стилизации и JavaScript для интерактивности).

## 📅 План разработки (Roadmap)
- [ ] Создать базовую структуру и семантическую разметку (`index.html`)
- [ ] Подключить стили (`style.css`) и сделать адаптивный интерфейс для мобильных устройств
- [ ] Разработать логику тестов или интерактивных карточек на JavaScript
- [ ] Добавить базу данных медицинских терминов или учебных материалов
